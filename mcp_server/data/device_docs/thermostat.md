# Thermostat Troubleshooting

## Thermostat shows "offline" in the app
1. Confirm the thermostat's display is lit — a blank display usually means a power/wiring issue, not Wi-Fi.
2. Check the home Wi-Fi network is up; the thermostat only supports 2.4GHz networks.
3. Hold the button on the thermostat for 10 seconds to restart it, then reopen the app.
4. If still offline after 5 minutes, remove and re-add the device from the app's device list.

## Thermostat won't reach the target temperature
1. Check the mode (heat/cool/auto) matches what's needed — in "auto" mode the system picks based on a comfort range, which can look "stuck" if the range is wide.
2. Verify no open windows/doors near the thermostat are triggering the "open window" pause feature.
3. HVAC systems older than 15 years may be undersized for extreme weather; this is a system limitation, not a device fault.

## Temperature reading looks wrong
1. Direct sunlight or proximity to a heat vent can skew the sensor by several degrees — recommend relocating the thermostat if possible.
2. Compare against a separate room thermometer for 30 minutes before concluding the sensor is faulty.
3. If off by more than 5°F consistently, escalate for sensor replacement.

## Escalate to a human agent if
- The thermostat is unresponsive after a factory reset.
- The customer reports burning smells or visible damage (safety issue — escalate immediately).
