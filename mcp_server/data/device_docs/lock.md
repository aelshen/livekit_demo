# Smart Lock Troubleshooting

## Lock unresponsive to app commands
1. Check battery level — locks below 15% battery may drop Wi-Fi/Bluetooth connectivity to save power.
2. Confirm the lock still shows as "connected" in the app; if not, it may be out of range of the hub/router.
3. Router channel congestion (common with many 2.4GHz devices nearby) can cause intermittent command delays — moving the router to a less congested channel often resolves this.

## Lock jams or won't fully latch
1. This is almost always mechanical, not electronic — check the door strike alignment first.
2. Cold weather can cause minor swelling/misalignment in wooden doors; recommend the customer check physical fit before assuming a device fault.
3. If the deadbolt motor makes noise but doesn't move, this is a hardware fault — escalate for replacement.

## Auto-lock isn't triggering
1. Confirm auto-lock delay is configured (default is often off).
2. Auto-lock requires the door sensor (if present) to detect the door is closed — a miscalibrated sensor will block auto-lock.

## Escalate to a human agent if
- Motor makes grinding/repeated retry noises (hardware fault, may need replacement under warranty).
- Any report of the lock failing to secure the door at all (safety issue — escalate immediately).
